# Third-party materials

## OpenMoji sticker assets

`app/assets/stickers/` contains static OpenMoji artwork. These image assets are
licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/)
and are not relicensed by this repository's Apache-2.0 source-code license.
Their source project is [OpenMoji](https://openmoji.org/). The per-asset mapping
and original codepoints are documented in `app/assets/stickers/README.md`.

## Optional model binaries

No machine-learning model binary is included in the public release. A
deployment owner who adds one is responsible for verifying its provenance,
license, security posture, and compatibility, and for preserving any required
attribution.

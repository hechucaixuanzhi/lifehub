# Contributing

Please keep contributions privacy-safe and provider-neutral.

- Do not add real-person profiles, scraped social posts, private datasets,
  credentials, device IDs, database dumps, or uploaded media.
- Use fictional fixtures in tests and demos.
- Keep character, group and writing-project data boundaries explicit in APIs
  and tests.
- Do not add an API key to the client, a commit, an issue, or a screenshot.
- Include focused tests for any change that affects context selection, memory
  retrieval, synchronization, or deletion.

Open an issue before a large architectural change so the data and privacy
implications can be discussed first.
